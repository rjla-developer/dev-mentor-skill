# Histórico — versión 0.x

**Nada de esta carpeta sirve para juzgar `stack-canon` 1.0.**

Todo lo de aquí midió `dev-mentor` 0.x, una herramienta con nueve capacidades de las que
**siete se borraron** al recortar el alcance a lo que la evidencia sostenía.

| Archivo | Qué es |
|---|---|
| `comparaciones-0.x.md` | Cinco comparaciones sobre una skill de Alexa y una app Flutter |
| `brief-linkedin-0.x.md` | Documento de contexto escrito para la versión de nueve capacidades |
| `capturas/` | Nueve capturas de las corridas de Flutter |

## Por qué se conserva

**Justifica reglas vigentes.** La regla de "corre la app y mírala" —que hoy es parte del
pilar de pruebas— existe porque una corrida de aquí entregó 68 pruebas verdes, analizador
limpio, build compilando, y un encabezado encimado en pantalla. Y la de "una sola
pregunta antes de construir" existe porque otra corrida decidió sola que una feature vivía
en otra plataforma y perdió una hora.

**Documenta el recorte.** Siete capacidades se borraron porque siete comparaciones no las
sostuvieron. Eso es el argumento del proyecto aplicado a sí mismo, y borrarlo sería quitar
la única prueba de que el recorte fue por datos y no por cansancio.
